# 电小智

基于 Agnes 模型与 AGH 框架的宿舍用电分析智能体。

## 项目概述

电小智以宿舍用电管理中的真实问题为出发点，将用电数据整理、
统计计算与智能分析结合，帮助使用者了解用电变化及其相关因素。

作品使用 Agnes 模型进行智能分析，以 AGH 作为智能体运行与执行框架。
使用者可以在电小智网页中导入数据、查看统计结果并生成分析报告，
无需单独打开 AGH 页面完成日常操作。

## 主要功能

- 支持导入 Excel、CSV 和用电图片。
- 图片识别结果可预览、修改，核对后再导入。
- 以表格展示每日用电记录。
- 根据用电量和设置的电价计算估算费用。
- 结合常住人数、临时单人居住时段和天气数据分析用电变化。
- 通过 AGH 调用数据校验、用电分析和结果核验工具。
- 在电小智页面展示 Agnes 生成的智能分析报告。
- 支持报告复制和下载。

## 操作流程

1. 导入用电数据，或加载示例数据。
2. 核对每日记录，设置电价、人数等信息。
3. 查看用电统计与变化情况。
4. 点击智能分析，等待报告生成。
5. 阅读并保存分析结果。

## 数据与结果说明

示例数据来自团队提供的真实宿舍用电记录，
天气数据使用 Open-Meteo 提供的常州附近网格天气数据。

天气分组用于辅助比较用电情况，不代表实际空调开机记录。
节能情景结果属于基于输入条件的估算，不代表已经实现的节电效果。
